## 1. 调整目标与现状依据

主问题调整为：对一个已经具备业务能力的模型，能否将固定认证关系编译为计算图内的 Gate，在合法输入恒等通过的条件下，控制受保护子图执行，并通过共享浅层提供可用的公共服务？

现有 E2-A/B 证明小型 decoder 能记忆同模板任务；E2-C 中 Plain/CAN 均在未见模板上退化。T2 CAP/C0 的单 seed 200k-token dev pilot 已被判定 NO-GO；它不支持将退化归因于 Gate。468 项 CPU 回归通过证明工程路径可测试，不证明自然语言能力或密码学安全。

后续不再把从零训练 decoder 的泛化成功作为 Gate 插入实验的前置条件。现有代码、配置、freeze 和负向结果保留；T2 数据、指标、manifest 与诊断经验按兼容性复用，原 byte tokenizer、trainer 和四元组协议不强制迁移到预训练模型。

现行唯一下一步仍以根日志为准：完成已验收的固定 512-update train-only 诊断。建议将它作为有界收尾，无论成功或失败都归档；失败时修复会影响新路线的共性正确性问题，不自动追加从零训练预算。用户审阅本稿无需等待 GPU 诊断完成。

## 3. G0：Gate 最小构造修订

### 3.1 模块与接口

以下是逻辑接口，具体文件与 API 在实现设计中确定，不能误读为现有代码已支持：

- `FixedNeuralVerifier(credential) -> Evidence`：只读取规范 credential 和固定参数；不读取业务 hidden state 决定认证结果。
- `AuthorizationCoordinator(Evidence, trusted_request_context) -> CommittedRoute`：唯一权限提交点；请求方不能传入已授权结果。
- `GatedModelAdapter(tokens, credential, trusted_context) -> response`：在共享 prefix 后调用 Gate；dispatcher 只消费已提交路由。
- `PublicReadout(hidden) -> public_logits`：新增可训练 norm/head 或小型 adapter；不更新原骨干和原输出头。

Gate 仍在模型计算图中间。credential 使用独立结构化输入，不混入 prompt，不改变原模型 token 序列。验证 evidence 仅供可信内部协调和诊断，不能作为外部可转移 capability。

### 3.2 必须满足的计算契约

1. 合法输入采用硬决定，并将原 hidden state 恒等传给 suffix；不使用 sigmoid 缩放业务表示。
2. public head 训练不改变认证模式。`model.train()` 不得隐式启用软授权；原骨干保持 eval，防止 dropout 等改变参考路径。
3. 仅 public readout 进入 optimizer；固定验证参数不接收业务损失更新。
4. 先按授权索引分组，再执行 suffix；禁止全批深层前向后遮挡输出或仅做乘零。
5. 每条生成序列提交一次权限，后续 token 复用；KV-cache 绑定请求、模型版本及路径，不跨权限复用。
6. 认证计算使用独立精度策略，不随业务模型 autocast/量化改变；对规范域、溢出、非有限值及边界输入显式处理。
7. DENY 在业务分支执行前发生时，public head 与 suffix 均零调用；共享 prefix 可能已执行，必须单独计数。
8. 已授权执行中途发生模型异常，只保证停止且不切换到另一分支，不把已发生的调用记录成零调用。

### 3.3 权限与错误语义

基线能力模式沿用当前研究含义：规范且不满足 toy 关系的 credential 可进入 PUBLIC；合法 credential 可进入 PROTECTED；格式错误进入 DENY。PUBLIC 上遇到专业问题的学习式拒答属于能力指标，不等同于 coordinator 的 DENY。

如果部署采用显式 public/protected 服务入口，则公共入口只允许 PUBLIC；protected 入口认证失败必须 DENY，不能 fallback PUBLIC。该模式使用独立 policy ID，不能与上述基线模式混合统计。入口可由用户选择请求，但实际权限仍由可信策略与 credential 决定。

首轮不引入通用语义任务分类器作为权限提交点。专业问题在公共路径上偶尔答对，计入服务范围越界指标；只有未授权执行 suffix 才计为执行隔离失败。

## 4. P0/P1：预训练模型与插入方法

首选约 0.5B 量级、具有标准 decoder block 实现的现成指令模型。`Qwen2.5-0.5B-Instruct` 仅作为优先核查候选，本稿未验证其当前许可证、版本、任务表现或本机可用性，不预先宣布选型冻结。

先核对模型许可证、权重 revision/hash、依赖版本和目标任务表现。原模型若不满足预设任务效用门槛，允许在 dev 上按已登记候选顺序换模型；不得反复改写任务以制造 Gate 正向效果，也不转回从零训练。

具体步骤：

1. 使用原 tokenizer、chat template、特殊 token、位置编码、attention mask、final norm、LM head 和停止规则运行未改造模型，冻结 baseline artifact。
2. 保留原模块，重编排 forward。在完整 block 后插入 Gate，首轮不改 attention 算法、不量化、不使用不同精度制造比较差异。
3. 候选 cut 为完整深度约 1/2、2/3、3/4 对应的合法整数层边界；实现前记录实际层号，去重。
4. 先进行 batch=1、无 KV-cache 的参考实验，再扩展到 KV-cache 和 mixed batch。原模型和 CAN 使用同一运行配置。
5. 分别验证“未插入原模型 vs 恒等切分模型”和“恒等切分模型 vs 合法 credential 路由”，区分适配错误与 Gate 错误。

合法路径在同一 token 前缀下比较 logits，并在预定样本集比较 greedy token IDs。容差按设备、精度和算子配置在评估前固定；报告最大误差、allclose 和 token mismatch 数。任何不一致均记录并定位，不能通过放宽容差隐藏问题；有限样本一致不宣称全域逐比特等价。

P1 可先拒绝全部无效请求以检验零调用，不依赖 public head 训练成功；只有 P2/P3 才主张公共服务可用。

## 5. P2：共享子网络与训练边界

完整模型为 `F(x) = H_full(B_suffix(B_prefix(Embedding(x))))`。
公共模型为 `S(x) = H_public(B_prefix(Embedding(x)))`。

二者在运行时共享同一份 embedding 和 prefix，公共读出模块是新增参数。独立学生骨干不属于此主线。

先测直接截断接原 norm/LM head 的无训练基线；然后训练独立 public norm/head，必要时比较小型公共 adapter。若原 LM head 与 embedding 权重绑定，不得通过共享引用更新 embedding；可冻结原输出投影，仅训练独立 adapter，或使用明确计入存储成本的独立输出头。

公共任务使用真实答案监督与冻结完整模型的公开分布蒸馏。专业问题的公共路径仅使用明确拒答目标，不蒸馏教师的专业答案。损失权重和温度只在 train/dev 确定；冻结后由 validation 选择 cut/checkpoint，test 不参与选择。

公共读出模块效果不足时，优先后移 cut 或增加有限的公共 adapter。解冻共享前缀和端到端软门控作为后续独立实验，不进入首轮；它们会改变完整模型，不能继续主张保持原模型严格行为。

## 6. 能力分级与数据协议

首个场景定义为“基础信息服务 / 完整分析服务”，任务规则在观察模型输出前登记。

| 数据类别 | 内容 | 公共路径目标 | 完整路径目标 |
|---|---|---|---|
| CAP-public | 同一事实卡片中的单跳抽取、直接属性查询 | 正确回答 | 正确回答 |
| CAP-protected | 同一来源的多跳组合、比较或约束问题 | 按预定公共服务策略拒答/范围内回答 | 正确回答 |
| CAP-boundary | 改写、混合问题、信息不足问题 | 遵守范围，报告误答 | 保持原模型效用 |
| MEM（后续） | 模型曾学过、请求中未提供的合成事实 | 单独测泄漏和拒答 | 验证确实记住事实 |

复用 T2-CAP 的事实和任务结构，按新模型 tokenizer 重建 token 数据并建立新 suite ID，不复用旧 freeze。CAP 的 context 含事实，不主张其机密性。CAP 按 source group 隔离 train/dev/validation/test，并保留 held-out 问法。

MEM 不作为第一轮前置条件。随机事实必须先被原模型学习；如需定向微调，先独立完成并冻结业务模型，再插 Gate。未见过的随机事实不能用作完整模型能力门槛。

外部候选为 SQuAD 类抽取 QA 与 HotpotQA 类多跳 QA，待核对许可证、版本和预训练污染风险后再接入。两个数据集的准确率差异不能直接证明权限分级；主证据来自同来源任务配对。独立学生、真实工具调用和 MoE 暂缓。

## 7. P3：验收指标、对照与选择规则

| 维度 | 必须报告的内容 | 首轮判据 |
|---|---|---|
| 验证正确性 | reference 差分、边界/非规范输入、精度配置 | 预定验证集错误接受为 0；不解释为不可伪造性 |
| 执行隔离 | 每个 suffix block 的实际调用，batch/缓存/异常测试 | PUBLIC、预执行 DENY 的 suffix 调用为 0 |
| 完整能力保持 | 原模型与合法路径 logits、greedy tokens、任务 EM/F1 | 固定容差 allclose；预定生成对照 token mismatch 为 0 |
| 公共效用 | public EM/F1、错误拒答率、输出有效率 | 达到冻结的绝对效用门槛和相对原模型保留比例 |
| 服务范围 | CAP 专业问题回答率、refusal、其他输出 | 独立报告；不与执行越权合并 |
| 性能 | Gate、prefix、suffix 分段延迟，TTFT、每 token 延迟、吞吐、显存 | 与相同任务和长度设置的基线比较，报告收益和开销 |
| 可复现性 | 配置/模型/数据/tokenizer hash、seed、失败运行 | 正式公共头训练至少 3 seeds，报告均值与离散程度 |

公共效用绝对阈值、相对保留比例、拒答门槛和性能预算不能沿用 CIFAR 准确率或 T2 小样本门槛。P0 在 train/dev 阶段给出有业务依据的数值，写入独立 freeze 后才能启动 P2 正式训练；未冻结时仅允许标记为 exploratory 的 smoke。

选择满足公共效用门槛的 cut，再按预登记的公共延迟、cut 深度 tie-break 选定；不追求最大 public/protected 准确率差。按来源分组统计不确定性，避免把同源多模板当作独立样本夸大证据。

主要对照：原完整模型、无 Gate 的同构 early-exit/full 模型、外部 reference verifier 加相同 dispatcher、模型内 verifier 加相同 dispatcher。保持相同算法/参数/权限规则与模型权重；外部验证位置不同带来的 prefix 节省单独说明。公共头另做有/无蒸馏对照。原模型与插入后的同 checkpoint reference 是不同对照，不能混用。

## 8. G1/I1：认证构造研究与替换

G1 首先交付协议选择表：完整协议及安全目标、参数与安全依据、credential 编码、公开输入、神经算子覆盖、哈希/挑战与状态范围、参考实现、证明与测试计划、预计资源。Module-SIS 关系内核可以先做编译对象，但单个等式不等于完整身份协议；ML-DSA 可作为标准候选，不在本稿直接决定完整神经化。

固定输入域与允许的算子集，逐模块实现模算术、范数、比较和逻辑组合。若浮点模拟离散算术，提供中间值上界和精确性/误差证明；业务模型混合精度不得改变验证结果。需要普通代码完成的解析、哈希或状态明确披露，不能仅因封装成 nn.Module 就称为全神经验签。

首要性质是规范域上的 `V_nn(c)=1 => V_ref(c)=1`，随后研究 completeness。差分、边界测试是验证手段；全域主张另需证明、形式验证或完整有限域覆盖，有限随机测试不能替代。完整认证安全还依赖 reference 协议安全，不能从神经等价单独推出。

I1 冻结业务模型和任务数据，仅替换 verifier，以相同路由、数值和性能测试验收。若要抵抗 replay，独立设计 nonce、请求绑定与已消费状态；无状态前馈层不承担历史记忆。此时新增安全主张须单独审核，不自动继承旧 toy 结果。

## 9. 资源、停止规则与工程组织

沿用 E:/CAN 仓库，新增版本化 adapter、配置和实验输出，不新建独立工程，不覆盖 E1/E2/T2 artifact。GPU 推理、读出头训练为 SERVER_REQUIRED；接口、差分 fixture 和小模型 CPU 测试为 LOCAL_OK。

以现有 RTX A4000 16 GB 为候选环境，不预设 0.5B 训练一定适配。先测各 cut 的峰值显存、吞吐及完整评估时间；墙钟预算按实测 tokens/s 与评估周期估计，在正式训练前登记。GPU 时长目前未测，不能填写为已知分钟或小时。teacher/student 顺序执行、共享冻结权重或缓存公开蒸馏目标的策略须显式计入成本。

停止规则：P1 等价或零调用失败先修复正确性，不用训练补救；P2 公共效用失败按预登记 cut/adapter 候选处理，候选耗尽则记录负面结果；G1 超出资源可支持模块级编译结论，但不能假称完整验签已实现。

## 10. 审阅决定与批准后的同步范围

本稿建议批准：

1. 以冻结预训练模型加共享子网络为新主线，T2 从零训练改为诊断材料，独立 TS 降为可选对照。
